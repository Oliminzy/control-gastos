Publicar Gratis en GitHub Pages

Tu app online accesible en todo el mundo sin costo

Sigue estos sencillos pasos para poner tu app en línea gratis:

  1. Crea un repositorio en GitHub: Inicia sesión en tu cuenta de GitHub.com y haz clic en "New Repository". Ponle de nombre por ejemplo: control-gastos.
  2. Sube este archivo: Sube el archivo index.html directamente a tu repositorio. (Puedes arrastrarlo o mediante Git CLI/VS Code).
  3. Activa GitHub Pages: Ve a la pestaña Settings de tu repositorio → Menú lateral izquierdo Pages.
  4. Configura la Fuente: En "Build and deployment" > "Source", selecciona Deploy from a branch y elige la rama main (o master) / folder /root. Guardar.
  5. ¡Listo! En 1 minuto GitHub te dará un enlace único público del estilo https://tu-usuario.github.io/control-gastos/.
